# Inter

`inter-latin.woff2` is the unmodified Latin, upright variable-weight (100–900)
Inter font served by Google Fonts and used by this app’s `next/font/google`
build. The desktop setup embeds it so the same typography is available before
the server starts, without an internet request.

Source: https://fonts.google.com/specimen/Inter
Project: https://github.com/rsms/inter
License: [SIL Open Font License 1.1](./OFL.txt), copied from
https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt.

Bundled from Next’s generated Inter Latin face on 2026-10-06. Its generated
stylesheet identifies normal style, weights 100–900, and Latin Unicode ranges.
Keep the license alongside the font when packaging the desktop app.
