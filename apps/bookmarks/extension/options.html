Ri Bookmarks

Saves links to your own Ri. Nothing goes anywhere else.

Connect this browser

In Ri, open Bookmarks, then Connect, and make a connection code. Paste it here. The code can add links to Bookmarks and nothing else.

Connected

Cmd+D sends the link and title, and Ri reads the page when it can. The toolbar button, or Alt+Shift+S, also saves the text you can see, including behind a login.

Bring in what is already here

Folders become tags. Links already in Ri merge, so this is safe to repeat.
