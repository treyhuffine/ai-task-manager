# Finances app

Source is maintained in Ri's `apps/finances` workspace. Commit coordinated changes from the repository root. Use the shared workspace SDK through its public exports only. Ri's rules for its core schema and process state apply to Ri, while this app owns its separate schema, service and process state.

Use pnpm. Finance owns its database and server. Never import Ri source or access a Ri Home/database/credential store. Connector access is through the versioned broker interface only. Use exact integer minor units, indexed bounded queries, shared server operations, Drizzle-derived record types and append-only migrations. Treat receipts as untrusted evidence. No direct model API key requirement. Test disposable FINANCE_ROOT homes. Never connect real accounts, monitor real mail, publish or start production while developing without owner setup. No em dashes or semicolons in user-facing copy.

Managed host support lives in `src/lib/local-app/` and `scripts/local-app-service.ts`. The action registry generates the contract, MCP registration and workflow index. Add no handwritten second registry. View callbacks remain account-scoped, revision-checked and explicitly app-visible. Home opening is read-only. Preserve user drafts on refresh and distinguish staged scenarios from writes. Keep the private service status bounded and free of records, endpoints and credentials.

Build managed artifacts from the root with `pnpm finances:package`, or with `pnpm package:local-app` in this folder, on macOS arm64 Node 26.5.0, ABI 147. Packaging and dependency installation must not start runtime jobs or open a personal root. Workspace packaging exports the current public SDK into an isolated portable project and uses `pnpm-standalone-lock.yaml` for its independent resolution. Exported packages use their pinned vendor SDK and `pnpm-lock.yaml`. Native modules need an actual runtime probe. Do not silently rebuild a mismatched native addon on a consumer machine.

Verify `pnpm test`, `pnpm typecheck`, changed-surface lint and the official reference bridge test with `FINANCE_KIT_FIXTURE=release/local-app`. Use separate disposable data roots. Test two account scopes, in-flight revocation, worker leases/cursors with no open view, explicit apply/undo and read-only reopen. Current managed connector qualification is synthetic Gmail only. Missing provider capabilities remain unavailable.
